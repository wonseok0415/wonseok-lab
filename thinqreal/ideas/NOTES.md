**2026-08-07 (3) — 분석 자동화 파이프라인 구축 (`fieldvoice/pipeline/`):**
- 사용자가 1채널 인터뷰 녹음을 확보 → 분석 자동화를 앞당겨 구축 (Phase 2·3의 도구를
  선제 제작 — Phase 1 수동 판독도 이 도구의 단계별 출력으로 수행 가능)
- **구성**: 전사(로컬 faster-whisper, 선택 설치) → LLM 에이전트 4종(화자 라벨링·요약·
  맥락 분석·인사이트 도출, claude-opus-5) → `output/<세션>/` 마크다운 저장.
  웹 UI(Flask, 로컬 전용) + `run.sh` 원클릭 실행 + 샘플 전사(가상 데이터) 동봉
- **1채널 대응**: 화자 라벨링을 전용 에이전트로 — 내용 기반 구분(화자 분리 사다리 2번).
  프롬프트 캐시로 요약·맥락·인사이트 3단계가 전사 전문을 공유 (과금 절감)
- **개인정보**: uploads/·output/·오디오 확장자 전부 .gitignore, README §0에 경고.
  전사 텍스트가 Claude API로 나가는 처리 방식을 동의서에 반영해야 함 (미결정 사항에 연동)
- **검증 상태**: 문법·웹 UI·오류 표면화는 샌드박스에서 확인. **실 LLM 호출·Whisper 전사는
  미검증**(샌드박스에 API 키·모델 다운로드 없음) — 맥북에서 `bash run.sh` 후 "샘플 전사로
  시험" 버튼이 첫 검증
