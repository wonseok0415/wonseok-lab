# FieldVoice 추진 보고 — 현장 목소리 수집·분석 시스템

> **2026-08-20 기준 · 주간 보고/컨센서스 미팅용** (발표자료 원본 — 수정 시 이 md 먼저)
> 상세 설계: `DESIGN.md` / 운영·이관 분석: `OPERATIONS.md`

## 1. 배경 — 왜 만들었나

- ThinQ Real 방문의 고객 목소리는 현재 **방문 후 설문**으로만 수집된다. 설문은 기억과
  체면 필터를 거친 정제된 답변이라, **시연 순간의 즉석 반응·질문·잡담은 증발**한다.
- 공간 운영 목적 세 축(쇼룸 지원 · 기술 검증 · **데이터 축적**) 중 "현장 발화 데이터"가
  빈칸이었다 — FieldCheck가 기계(ThinQ ON)의 상태를 축적하듯, 사람의 목소리를 축적하는
  짝 시스템이 필요하다는 문제의식.
- 질문 설계는 자동차 업계 고객 리서치 방법론을 AI홈에 이식: **"왜?"라고 묻지 않고,
  제품이 아니라 삶을 묻는다** (로망·부러움·아쉬움·경계·미래일기 5유형 프레임).

## 2. 시스템 개요 — 어떻게 동작하나

```
현장 녹음 (도슨트 진행, 시연 슬롯 중)
  → 전사 (로컬 Whisper — 음성이 장비 밖으로 나가지 않음)
  → AI 분석 4단계 (화자 라벨링 → 요약 → 맥락 분석 → 인사이트 도출)
  → 1페이지 리포트 (한 줄 결론 · 핵심 인사이트 TOP5 · 개선 제안 3 · 검증 가설)
  → 관리자 페이지 적재 (🎙 현장 인사이트 탭 — 관리자 3인 열람, 회차별 축적)
```

- **추가 비용 0원**: 기존 자산 재활용 — 상주 노트북(FieldCheck와 공용, 시간대 상보),
  구독형 AI(Claude, 별도 과금 없는 백엔드), 기존 백엔드(Apps Script) 순수 추가
- **개인정보 설계**: 원본 음성·전사는 현장 장비 로컬에만 보관(검수 후 파기), 관리자
  페이지에는 **가명화된 1페이지 요약만** 업로드(수동 확인 게이트 필수). 녹음 고지는
  현장 구두 + 서면 1장(문안 확정 예정)
- FieldCheck 선례(메인 시스템 무변경·순수 추가·이관 대비 설정 분리)를 그대로 준수 —
  사내 이관 시 교체 지점은 API 주소·키 / AI 백엔드 / 파일 경로 3곳뿐

## 3. 파일럿 검증 결과 (8월 2~3주)

**8/5 계열사 방문 76분 실녹음**으로 전 과정을 검증했다.

| 항목 | 결과 |
|---|---|
| 파이프라인 완주 | 녹음 → 전사(약 40분) → 분석(수 분) → 1페이지 리포트, 추가 비용 0원 |
| 전사 품질 | 요지 파악 충분·인용은 검수 필요 → whisper medium 채택, 환청 압축 필터 등 실측 개선 5건 반영 |
| **분석 신뢰도 벤치마크** | 자동 분석 vs 별도 수동 정밀 판독 비교 — **핵심 결론 일치 + 자동만 잡은 발견 4건** (녹음 고지의 발화 위축 상관, '한계 자인→발화 유발' 패턴 등) |
| 운영 모델 확정 | **자동 분석 기본 + 사람 검수 1회** (인용 확인·가명화) |

**파일럿이 실제로 낸 인사이트 (예시)**
- 조명·커튼 자동화(저비용 구성)만으로 "집에 들어올 때의 기분"이 바뀌고 가사 분담까지
  변화 — 정서 전환이 구매 동인이라는 서사 확보
- 구축 아파트 **개별 가구 설치 불가**가 방문객 관심이 이탈하는 정확한 지점으로 관측
- 시연 운영 개선 3건 도출: 시연 대기 구간을 질문 슬롯로 활용, 녹음 고지는 시작 시
  1회로 제한, 자기개방 후 되묻기 스크립트화

## 5. 컨센서스 요청 — 팀장 결정 필요 3건

1. **정식 운영 전환 여부** — 다음 방문 회차부터 질문 프레임 실전 투입 + 회차별 리포트
   축적 시작 (그룹 시연형/인터뷰형 프로토콜 분리 운영)
2. **녹음 동의 절차 확정** — 현장 구두 고지 + 서면 1장 방식. 사내 컴플라이언스 확인
   경로 지정 필요
3. **AI 분석 백엔드의 계정 문제** — 현재 개인 구독으로 무과금 운영 중이나, 전용
   노트북(공용 장비)에는 개인 계정을 상주시키지 않는 것이 원칙. **사내 Claude Code
   사용 신청**(이관 회의 액션 #8과 동일 트랙)의 우선 처리 요청
