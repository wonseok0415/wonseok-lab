## 1. 배경 — 왜 시작했나

- ThinQ Real은 ThinQ ON(생성형 AI 음성 허브) 기반 AI홈 솔루션의 동작성을 매일 수동 점검 중
- **2026-07-27 주간 ATOM TTS 서버 장애**: 월 오후 무응답 증가 → 화 오전 시연 불가 수준(일반 고객 가정에서도 재현) → 화 12시 LG TTS 대안 확보로 복구
- 경영진 지시: *"단건 해결을 넘어, 음성을 포함한 ThinQ ON 서비스 운영을 체계적으로 모니터링하고 이슈·장애에 대응하는 운영 프로세스를 즉시 수립할 것"*
- 핵심 통찰: 장애 증상은 '발화 후 무응답' — **주기적으로 말을 걸어 응답만 확인해도 반나절 이상 조기 감지 가능했던 장애**

## 2. 초기 기획 (2026-07-30 팀장 보고)

- **컨셉**: 점검 리그(장비)가 사람 대신 ThinQ ON에게 주기적으로 말을 걸고, 응답을 자동 판정·기록·알림하는 "감지→알림→판단→기록" 루프
- **Phase 1**: 수동 일일 체크리스트 즉시 가동(운영 공백 제로) + 자동 점검 시스템 구축·검증 (수동·자동 병행으로 판정 일치 확인)
- **Phase 2**: 검증된 시스템의 정식 운영 격상 (점검 무인화, 대시보드, 보안 검토)
- **판정 3단계**: L1 응답 유무·지연 / L2 내용(STT 키워드) / L3 실제 동작(전·후 촬영)
- **비용 원칙**: 유휴 노트북 + 기존 예약 시스템 백엔드(Apps Script+Sheets) 재활용 — 신규 구매는 USB 웹캠 1대 수준

## 3. 진행 경과

### 구축 (07-30)
- 수동 일일 체크리스트 6항목 확정 (일상 대화를 순수/서비스 연계로 분리 — 엔진 장애와 AccuWeather 연동 장애를 구분 진단)
- 점검 리그 프로그램(Python) 완성: 음성 재생 → 응답 녹음 → L1 자동 판정 → 서버 전송(+로컬 백업) → 실패 알림. Windows/macOS 양쪽 지원
- 백엔드: 실서비스 Apps Script에 health_check 엔드포인트 이식 (기존 코드 무변경, 순수 추가)

### 현장 테스트에서 발견·해결한 이슈 4건 (07-30~31)
| 발견 | 해결 |
|------|------|
| 기동어 후 '띵' 반응 전 명령이 씹힘 | 기동어·명령 분리 재생 + 대기 1.5초 |
| 검색성 질문에서 연산 대기음('띵띵띵')을 응답으로 오판 → **TTS 장애를 놓칠 구멍** | 발성 비율 판정(1초 창 70%) — 효과음 배제, 말소리만 인정 |
| 생성형 답변이 길어 다음 점검의 기동어를 씹음 | 시나리오 간 "조용해질 때까지 대기" (판정 결과와 무관하게 항상) |
| 에어컨·선풍기 소음 환경에서 정상 응답을 실패로 오판 | 적응형 판정 — 음성 대역(250~4000Hz) + 소음 바닥 자동 추정 + 바닥+8dB 기준 |

### 검증 결과 (07-31)
- **소음 환경(에어컨·선풍기 가동) 현장 점검 실패 0건** — 3개 시나리오 전체 통과
- 판정 로직 자체 검증 7건 통과 (무응답/순간 소음/연산음/쉼 있는 말소리/팬 소음/소음 위 말소리 등)
- 서버 파이프라인 완성: Sheets `health_checks` 자동 기록 + **일일 아침 요약 메일** 수신 확인
- 측정치 A-가중(dBA) 표기 + 실측 1점 교정 완료 (휴대폰 소음계 42dBA 기준) — 직관적 판독 가능
- 운영 배려: 테스트 단계 알림은 운영자 1인에게만, 건별 알림 대신 일일 요약 (담당자 피로 최소화). 24시간 무기록 시 "리그 미가동 의심" 경고 — 침묵을 정상으로 오인하지 않는 설계

### 부수 성과
- 실서비스 소스 이원화 혼선을 발견·정리 — 구버전 배포로 인한 운영 장애 리스크 원천 차단, 저장소 역할 확정(thinqreal=실서비스, wonseok-lab=FieldCheck)

## 4. 현재 상태

- **구축 1단계(L1 무응답 감지) 완주 직전** — 남은 마감: ① 익일 아침 자동 요약 메일 확인 ② 브랜치 main 머지
- 시스템 구성: 리그(맥북, 검증용) → Apps Script → Sheets → 일일 요약 메일
- 데이터 축적 시작: 점검 이력·응답 지연·dBA가 Sheets에 쌓이는 중
