## 3. 20분 구성 (씬 단위 설계)

20분 = 1,200초. 영상 생성 AI는 5~10초 클립 단위 → **총 150~200컷 예상.**
**확장 흐름:** 빛이 깨어남 → 집 → 이동 → 오피스 → 도시 → 모든 공간의 연결. 공간 스케일이 단계적으로 커진다.

```
[ 오프닝 ]    0:00 - 1:00    데이터/빛 입자가 깨어나 공간의 윤곽을 이룸 / (후반 합성) 타이틀·슬로건
[ Ch.1 집 ]   1:00 - 5:30    The Home that Cares — 공간이 거주자를 돌본다
                            새벽→아침. 빈 집의 천장·벽·바닥이 '보이지 않는 안무'로 깨어남.
[ Ch.2 이동 ] 5:30 - 10:00   The Space that Moves — 슈필라움: 이동조차 또 하나의 거실
                            LG×기아 PV5형 모빌리티 공간. 가변 모드(라운지·스튜디오)·가전·ThinQ ON.
[ Ch.3 관리 ] 10:00 - 14:30  The Spaces in Concert — 하나의 집에서 여러 공간으로
                            ThinQ Pro: 빌딩·단지의 수많은 공간이 하나의 지능으로 조율된다.
[ Ch.4 도시 ] 14:30 - 19:00  The City in Tune — 지능이 도시 스케일로
                            친환경 에너지·인프라·데이터가 조율되는 항공 시네마틱.
[ 연결+엔딩 ] 19:00 - 20:30  Borderless — 집·차·오피스·도시가 빛의 네트워크로 하나가 됨 + 슬로건
```

> 각 본편 챕터 ≈ 4.5분 → 5~10초 클립 약 30~40컷. 챕터 단위로 룩(컬러·조명)을 통일한다.

### 🔑 두 가지 제작 규율 (앞선 비판 분석 반영)

1. **FAST 자핑 훅:** 오프닝 **첫 10~15초**에 "공간=지능"의 강렬한 비주얼 한 방. 추상 데이터 서사는 그 *다음*에 푼다. (자핑 시청자 이탈 방지)
2. **마이크로 비트(micro-beat):** **약 90초마다** 미세 페이오프(빛의 반응·공간의 움직임·스케일 전환)를 배치해 무인물 20분의 단조로움을 깬다. → 씬 시트에 비트 단위로 표기.
3. **온스크린 텍스트(인터타이틀):** 무자막이 아니다. 후반 합성으로 **미니멀 한·영 인터타이틀**을 챕터 전환마다 1줄(+타이틀+클로징 = 총 6회 내외). 흐름 안내용 시(詩)적 카피만, 다큐 내레이션은 지양. (AI 생성 X)

### 🎯 "비가시적 인과"의 프롬프트 번역 규칙 (가장 중요한 제작 노하우)

AI 영상은 '온도·예지·0.3초 전' 같은 **비가시적 인과를 직접 못 찍는다.** 반드시 **시각 대리물**로 번역한다.

| 전달하려는 의미 | ❌ 직접 묘사 | ✅ 시각 대리물(프롬프트) |
|----------------|-------------|------------------------|
| 따뜻함/온도 상승 | "바닥이 데워진다" | warm amber glow spreading across the floor surface |
| 예지(미리 안다) | "일어서기 1초 전" | light gently flowing ahead toward the direction of movement |
| 환기/공기 조정 | "공기를 정화한다" | soft air particles drifting, curtains breathing subtly |
| 돌봄/감응 | "공간이 반응한다" | surfaces softly illuminating in response, ripple of light |

> 화면 내 **텍스트·자막·타이포·로고는 AI 생성 금지** → 모두 **후반 편집에서 합성**. 프롬프트엔 `no text` 명시.

## 4. AI 프롬프트 작성 규칙 (★ STUDIO341 제출물)

프롬프트 자체가 제출 항목이므로 **재현 가능하게** 기록한다.

### 4-1. 표준 포맷
```
[Subject]   주제·피사체
[Scene]     배경·환경
[Camera]    샷 종류·움직임 (slow dolly-in, aerial orbit 등)
[Lighting]  조명·시간대 (golden hour, soft morning light)
[Style]     화풍·질감 (cinematic, anamorphic 50mm, photorealistic)
[Mood]      분위기 (serene, warm, awe)
[Tech]      16:9, FHD+, duration
[Negative]  배제 요소 (no text, no logos, no humans/distortion)
```

### 4-2. 고정 스타일 블록 (전 컷 재사용 → 톤 일관성)
```
cinematic, anamorphic 50mm lens, shallow depth of field, subtle lens flare,
soft volumetric light, subsurface scattering, warm amber + deep navy palette,
bioluminescent cyan light accents, photorealistic, ultra-detailed, 16:9, FHD+
```
### 4-3. 고정 네거티브 블록
```
no text, no captions, no logos, no humans (or backlit silhouette only),
no distortion, no warped geometry, no extra fingers, no watermark, no flicker
```

### 4-4. 기록 원칙
- 사용 도구·모델·버전·시드(seed)·파라미터 보존 → 재현성
- 채택 vs 폐기 프롬프트 구분, 후보정(업스케일·색보정) 단계도 기록
