## 2. 장르별 전략 비교 (AI 제작 난이도 관점)

| 장르 | 장점 | 난이도 리스크 | AI 적합도 |
|------|------|---------------|-----------|
| **Ambient** (풍경·휴식 영상) | 캐릭터·대사·립싱크 불필요, 20분 채우기 쉬움, 아티팩트 숨기기 용이 | 단조로움 → 구성·음악·전환으로 극복 | ★★★★★ (가장 안전) |
| **Infotainment** (정보+오락) | 내레이션으로 흐름 명확, 메시지 전달력 | 정확한 정보·일관된 비주얼 필요, 내레이션 제작 | ★★★☆☆ |
| **Kids** (키즈) | 수요 큼, 밝은 비주얼 | **캐릭터 일관성 유지가 가장 어려움**, 안전성 검수 | ★★☆☆☆ |

> **권장 출발점: Ambient.** 20분 분량·완성도·제작 속도 면에서 AI 생성에 가장 유리.
> 차별화를 원하면 "Ambient + 가벼운 내레이션/스토리" 하이브리드도 고려.
> (최종 선택은 사용자 결정 — 위는 제작 효율 관점의 추천일 뿐)

## 3. 20분 구성 템플릿 (씬 단위 설계)

20분 = 1,200초. 씬을 단위로 쪼개 관리한다. (영상 생성 AI는 보통 5~10초 클립 단위)

```
[ 오프닝 ]      0:00 - 0:30   타이틀 + 분위기 제시
[ 본편 챕터 1 ] 0:30 - 7:00   테마 A (예: 새벽)
[ 본편 챕터 2 ] 7:00 - 14:00  테마 B (예: 한낮)
[ 본편 챕터 3 ] 14:00 - 19:30 테마 C (예: 황혼/밤)
[ 엔딩 ]        19:30 - 20:00+ 마무리 + (선택)크레딧
```

### 씬 관리 표 (실제 작업 시 이 표를 채워나감)

| 씬# | 챕터 | 길이 | 장면 설명 | 영상 프롬프트(요약) | 사운드 | 상태 |
|-----|------|------|-----------|---------------------|--------|------|
| S01 | 오프닝 | 0:00–0:08 | … | … | BGM intro | ☐ |
| S02 | … | … | … | … | … | ☐ |

> 클립이 많아지므로 **씬 번호·파일명 규칙**을 정해두면 후반 합성이 쉬워진다.
> 예: `S01_opening_v2.mp4`, `S14_dusk_lake_v1.mp4`

## 4. AI 프롬프트 작성 규칙 (★ STUDIO341 제출물)

프롬프트 자체가 제출 항목이므로 **재현 가능하게** 기록한다.

### 4-1. 영상/이미지 생성 프롬프트 표준 포맷
```
[Subject]   주제·피사체
[Scene]     배경·환경
[Camera]    샷 종류·움직임 (예: slow dolly-in, aerial)
[Lighting]  조명·시간대 (golden hour, soft morning light)
[Style]     화풍·질감 (cinematic, 35mm film, photorealistic)
[Mood]      분위기 (serene, nostalgic)
[Tech]      16:9, FHD+, duration
[Negative]  배제 요소 (no text, no people, no distortion)
```

### 4-2. 기록 원칙
- 사용 도구·모델·버전 명기 (예: Runway Gen-3 / Veo / Kling 등)
- 시드(seed)·파라미터 값 보존 → 재현성·일관성
- 채택 프롬프트 vs 폐기 프롬프트 구분
- 후보정(업스케일·색보정) 단계도 프롬프트/툴 기록

### 4-3. 일관성 유지 팁
- 동일 톤 유지를 위해 스타일 키워드를 **고정 블록**으로 재사용
- 챕터별 컬러 팔레트·룩 사전 정의 후 모든 프롬프트에 삽입

## 5. 제작 파이프라인 (도구 매핑)

| 단계 | 작업 | 도구 후보 | 비고 |
|------|------|-----------|------|
| 기획·대본 | 콘셉트·구성·프롬프트 설계 | **Claude (Chat)** | 이 문서 기준 적용 |
| 영상 생성 | 클립 생성 | Runway / Veo / Kling / Pika / Sora 등 | Claude는 영상 직접 생성 불가 |
| 이미지 | 키비주얼·썸네일 | Midjourney / DAL-E / Firefly | |
| 음성 | 내레이션(있을 경우) | TTS(ElevenLabs 등) | 다국어 방영 고려 시 유의 |
| 음악 | BGM·환경음 | Suno / 라이선스 음원 | **저작권·상업 이용 가능 여부 필수 확인** |
| 자막 | SRT·번역 | 자동 생성 후 검수 | 글로벌 채널 → 영문 자막 고려 |
| 편집·합성 | 컷 편집·색보정·인코딩 | 편집툴 / `ffmpeg` | FHD+·16:9·20분+ 최종 검증 |

> 5·6·7번의 **반복/배치 작업(자막 생성, TTS 일괄, ffmpeg 합성·인코딩)** 은
> Claude **Code** 환경에서 스크립트로 자동화하는 것이 효율적 (필요 시 이 저장소에 구축 가능).
