## 1. 기획 의사결정 (✅ 확정)

| 항목 | 확정 내용 |
|------|-----------|
| **장르** | 브랜드 비전 필름 — **시네마틱 앰비언트 + 가벼운 인포테인먼트 하이브리드** |
| **콘셉트** | **"경계를 넘는 공감지능 (Borderless Affectionate Intelligence)"** — 집→모빌리티→도시로 확장되는 LG 공감지능 비전을, **인물 없이 공간·빛·인터페이스 중심**으로 그린 시네마틱 앰비언트 필름 |
| **핵심 메시지** | LG 공감지능(Affectionate Intelligence)이 집의 경계를 넘어 삶의 모든 공간을 따뜻하게 연결한다 (*Innovation in Tune with You*) |
| **타깃 시청 맥락** | 글로벌 LG채널 — 거실 대화면 감상 / 브랜드 무드 필름 (대사 의존 없이 비주얼·음악으로 전달) |
| **톤앤매너** | 시네마틱 · 근미래 · **따뜻한 테크(warm-tech)** — 차가운 SF가 아니라 '공감'에 맞는 부드러운 빛·자연 소재·은은한 인터페이스 글로우 |
| **분량 배분** | 오프닝 1분 + 본편 4챕터(각 ~5.5분) + 엔딩 1.5분 = **20분+** (3번 참고) |
| **사운드 전략** | **내레이션 최소/무 + 시네마틱 앰비언트 BGM 중심** + 공간 사운드 디자인. (글로벌 방영 고려 — 대사 없이 보편적 전달) |
| **인물 처리** | **무인물 원칙** — 캐릭터 일관성 리스크 회피. 필요 시 실루엣·손·뒷모습만 한정 사용 |
| **개인 / 팀** | (미정 — 사용자 확정 필요) |

> **무인물 + 공간 중심**을 택한 이유: AI 영상 생성의 최대 난관인 '캐릭터/인물 일관성' 문제를
> 원천 회피하면서, 빛·공간·인터페이스의 시네마틱 연출로 완성도를 끌어올릴 수 있다.

## 2. LG 공감지능 비전 레퍼런스 (콘셉트 근거)

콘텐츠가 LG의 **공식 미래 비전**과 정렬되어야 심사(2차 MS본부 임원) 설득력이 높다.
아래 키워드를 비주얼·구성의 근거로 삼는다.

| 비전 요소 | 내용 | 영상 내 표현 |
|-----------|------|--------------|
| **공감지능 (Affectionate Intelligence)** | LG의 AI 철학 — AI가 사용자를 이해·돌봄 | 전체를 관통하는 정서: '따뜻한 기술' |
| Real-Time Life Intelligence | 안전·보안·건강을 실시간 돌봄 | Ch.1 (집의 돌봄) |
| Orchestrated Intelligence | 기기·공간이 자율적으로 조율 | Ch.1~2 (스스로 어우러지는 공간) |
| Responsible Intelligence | 보안 기반 초개인화 | Ch.2~3 (나에게 맞춰지는 공간) |
| **"AI in Action" 확장** | 집 → 모빌리티(AI-defined Vehicle) → 도시·데이터센터 | 4챕터 구조의 뼈대 |
| **Zero Labor Home** | 가사노동 제로 비전 (CES 2026) | Ch.1 |
| **LG CLOi 로봇** | 가정용 AI 로봇 | Ch.1 (로봇 모티프, *실제 제품 정밀 묘사 대신 '정신' 표현*) |
| **슬로건** | *"Innovation in Tune with You"* | 오프닝/엔딩 카피 |

> ⚠️ **브랜드 정확성 주의:** 실제 LG 로고·특정 제품 모델을 부정확하게 재현하지 않는다.
> AI 생성물은 제품을 '있는 그대로' 흉내내기보다 **비전의 '분위기와 정신'을 추상적으로** 표현한다.
> (예: 구체적 가전 모델 대신, 빛·인터페이스·공간감으로 '공감지능이 깃든 공간'을 연출)

## 3. 20분 구성 템플릿 (씬 단위 설계)

20분 = 1,200초. 씬을 단위로 쪼개 관리한다. (영상 생성 AI는 보통 5~10초 클립 단위 → 총 200여 컷 예상)

**구성 흐름:** 어둠 속 빛이 깨어남 → 집 → 차(이동) → 도시 → 모든 공간의 연결. 공간 스케일이 점점 확장된다.

```
[ 오프닝 ]   0:00 - 1:00    어둠 속 빛이 깨어나는 공감지능 / 타이틀 / "Innovation in Tune with You"
[ Ch.1 집 ]  1:00 - 6:30    The Home that Cares — Zero Labor Home
                            새벽→아침. 빈 집의 기기·조명·로봇이 스스로 깨어나 어우러짐.
                            (Real-Time Life / Orchestrated Intelligence)
[ Ch.2 이동 ]6:30 - 12:00   The Space that Moves — AI-defined Vehicle
                            미래 차량 실내가 거실처럼. 이동=또 하나의 생활공간. 창밖 풍경 흐름.
                            (Responsible / 초개인화 — 공간이 나에게 맞춰짐)
[ Ch.3 도시 ]12:00 - 17:30  The City in Tune — AI 도시·지속가능
                            스케일 확장. 도시 인프라·친환경 에너지·데이터센터가 조율되는 항공 시네마틱.
[ Ch.4 연결 ]17:30 - 19:30  Borderless — 집·차·도시가 빛의 네트워크로 하나가 됨
[ 엔딩 ]     19:30 - 20:00+ 메시지 카피 + 슬로건 + (선택)크레딧
```

> 각 본편 챕터 ≈ 5.5분 → 5~10초 클립 약 40~60컷. 챕터 단위로 룩(컬러·조명)을 통일한다.

## 4. AI 프롬프트 작성 규칙 (★ STUDIO341 제출물)

프롬프트 자체가 제출 항목이므로 **재현 가능하게** 기록한다.

### 4-1. 영상/이미지 생성 프롬프트 표준 포맷
```
[Subject]   주제·피사체
[Scene]     배경·환경
[Camera]    샷 종류·움직임 (예: slow dolly-in, aerial)
[Lighting]  조명·시간대 (golden hour, soft morning light)
[Style]     화풍·질감 (cinematic, 35mm film, photorealistic)
[Mood]      분위기 (serene, nostalgic)
[Tech]      16:9, FHD+, duration
[Negative]  배제 요소 (no text, no people, no distortion)
```

### 4-2. 기록 원칙
- 사용 도구·모델·버전 명기 (예: Runway Gen-3 / Veo / Kling 등)
- 시드(seed)·파라미터 값 보존 → 재현성·일관성
- 채택 프롬프트 vs 폐기 프롬프트 구분
- 후보정(업스케일·색보정) 단계도 프롬프트/툴 기록

### 4-3. 일관성 유지 팁
- 동일 톤 유지를 위해 스타일 키워드를 **고정 블록**으로 재사용
- 챕터별 컬러 팔레트·룩 사전 정의 후 모든 프롬프트에 삽입
